# 🔌 Projetos e Sistemas Embarcados com Arduino

Repositório dedicado ao desenvolvimento de circuitos, automação e sistemas embarcados utilizando a plataforma **Arduino** e linguagem **C/C++**.

---

## 🛠️ Tecnologias e Ferramentas
- **Linguagens:** C / C++ (Arduino IDE)
- **Hardware:** Arduino Uno / Nano, Sensores, Servo Motores, Buzzers e Botões
- **Simulação & Modelagem:** Tinkercad

---

## 📂 Projetos Incluídos

### 🚥 1. Semáforo Composto
- **Descrição:** Automação do ciclo de funcionamento de um semáforo de trânsito (Verde, Amarelo e Vermelho) com controle de tempo de acionamento.
- **Componentes:** Arduino, LEDs (Vermelho, Amarelo, Verde) e Resistores.
- **Código-fonte:** [`semaforo composto/semaforo.ino`](./semaforo%20composto/semaforo.ino)

### 🔊 2. Sinalizador Sonoro (Buzzer + Pushbutton)
- **Descrição:** Acionamento de alerta sonoro via interrupção manual por botão de pressão.
- **Componentes:** Arduino, Buzzer, Pushbutton e Resistor Pull-down/Pull-up.
- **Código-fonte:** [`buzzer pushbutton/buzzer.ino`](./buzzer%20pushbutton/buzzer.ino)

### 📏 3. Medição de Distância (Sensor Ultrassônico)
- **Descrição:** Leitura de tempo de eco de onda ultrassônica para cálculo preciso de distância em centímetros.
- **Componentes:** Arduino, Sensor Ultrassônico HC-SR04.
- **Código-fonte:** [`sensor ultrassonico/sensor.ino`](./sensor%20ultrassonico/sensor.ino)

### ⚙️ 4. Controle de Posição (Servo Motor)
- **Descrição:** Controle angular e posicionamento preciso de atuador servomotor utilizando sinal PWM.
- **Componentes:** Arduino, Micro Servo SG90.
- **Código-fonte:** [`servo motor/servo.ino`](./servo%20motor/servo.ino)
