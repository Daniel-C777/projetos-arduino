# 🔌 Projetos e Sistemas Embarcados com Arduino

Repositório dedicado ao desenvolvimento de circuitos, automação e sistemas embarcados utilizando a plataforma **Arduino** e linguagem **C/C++**.

---

## 🛠️ Tecnologias e Ferramentas
- **Linguagens:** C / C++ (Arduino IDE)
- **Hardware:** Arduino Uno / Nano, sensores e atuadores diversos
- **Simulação & Modelagem:** Tinkercad / Fritzing
- **Documentação:** Diagramas de circuito e esquemáticos elétricos
